# 🚀 **Resume & Job Description Matcher — Project Discussion (Frontend: Next.js)**

## ✅ **1. Project Overview**

The Resume & Job Description Matcher is a web application that evaluates how well a candidate’s resume aligns with a given job description.
It uses NLP/ML (or an LLM API like OpenAI) to compute the match percentage and provide insights such as:

* Skill matching
* Missing skills
* Keyword suggestions
* Resume improvement tips
* Detailed match score breakdown

The **frontend is built in Next.js**, providing a fast, SEO-friendly, and modern user experience.

# 🌐 **4. Frontend–Backend Flow**

### **Step-by-step Flow**

1. **User uploads resume**
   → sent to `/api/parseResume`
   → backend extracts text using pdf-parse, docx-parser, or LLM.

2. **User enters job description**
   → stored locally until user clicks Match.

3. **User clicks “Match Resume”**
   → POST request to `/api/match`
   → Body: `{ resumeText, jobDescription }`

4. **Backend NLP/LLM processes data**
   → returns match score, matched skills, missing skills, suggestions.

5. **Results displayed in the dashboard**.

# ⚙️ **3. How to Use Gemini API in Your Next.js Project**

Gemini provides a REST API you can call from a **Next.js API route** like:

```
/api/ai-assistant
```

### Example (server-side) using Gemini 2.0 API:

```ts
import { NextResponse } from "next/server";

export async function POST(req: Request) {
  const { prompt } = await req.json();

  const result = await fetch(
    "https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateText?key=" + process.env.GEMINI_API_KEY,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        prompt: { text: prompt },
        temperature: 0.6,
      })
    }
  );

  const data = await result.json();
  return NextResponse.json({ output: data });
}
```

### Then your frontend calls:

```ts
const res = await fetch("/api/ai-assistant", {
  method: "POST",
  body: JSON.stringify({ prompt: userInput }),
});
const data = await res.json();
```
