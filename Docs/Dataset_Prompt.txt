Generate a complete synthetic dataset for a resume–job matching NLP project. Requirements:

1️⃣ **Scope**
- Tech-focused dataset (software engineering, data science, web development, DevOps, AI/ML, etc.)
- 500 unique Job Descriptions (JDs)
- 200 unique Resumes
- Skills: tech skills (JavaScript, Python, React, Docker, SQL, etc.) + soft skills (Communication, Leadership)
- All text should be realistic, diverse, and non-repetitive

2️⃣ **File Structure**
- Root folder: dataset/
    - dataset/resumes/ → contains 200 resumes named resume_001.txt … resume_200.txt
    - dataset/jds/ → contains 500 JDs named jd_001.txt … jd_500.txt
    - dataset/match_pairs_labeled.csv → contains all possible resume–JD pairs with labels (1 = match, 0 = no match)
    - dataset/match_pairs_unlabeled.csv → contains all resume–JD pairs without labels
    - dataset/skills_tech.json → JSON array of all tech skills used
    - dataset/skills_common.json → JSON array of soft skills used

3️⃣ **Resume Example Format**
Each resume should include:
```

SUMMARY: <Brief professional summary>

SKILLS: <List of tech and soft skills>

PROJECTS:

* Project 1
* Project 2

EXPERIENCE:

* Job 1
* Job 2

EDUCATION:
Degree, Major, Graduation Year

```

4️⃣ **Job Description Example Format**
Each JD should include:
```

Title: <Job Title>
Experience: <Years of experience>
Location: <Remote/On-site/Hybrid>

Responsibilities:

* Responsibility 1
* Responsibility 2
* Responsibility 3

Required Skills:

* Skill 1
* Skill 2
* Skill 3

Nice to Have:

* Skill 1
* Skill 2

```

5️⃣ **match_pairs_labeled.csv Example**
```

resume_id,jd_id,label
resume_001.txt,jd_001.txt,1
resume_001.txt,jd_003.txt,0
resume_002.txt,jd_002.txt,1
resume_002.txt,jd_001.txt,0

```

6️⃣ **match_pairs_unlabeled.csv Example**
```

resume_id,jd_id
resume_001.txt,jd_001.txt
resume_001.txt,jd_003.txt
resume_002.txt,jd_002.txt
resume_002.txt,jd_004.txt

```

7️⃣ **Additional Requirements**
- All resumes and JDs must be unique and realistic.
- Labels in `match_pairs_labeled.csv` must be consistent with the skills match (1 = high match, 0 = low/no match).
- Generate JSON files for tech skills and common skills used in the dataset.
- Save all files in the `dataset/` folder as specified.
